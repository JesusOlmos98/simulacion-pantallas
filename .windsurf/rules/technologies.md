# Technologies Stack

## Frontend Framework
- **Next.js**: React framework with App Router
- **React**: UI library with TypeScript
- **TypeScript**: Type-safe JavaScript

## Styling
- **Tailwind CSS**: Utility-first CSS framework
- **Inline styles**: For dynamic values and component-specific styling
- **NO custom CSS files**: Avoid separate CSS files unless absolutely necessary
- **NO custom classes**: Prefer Tailwind utilities over custom CSS classes

## Icons
- **Lucide React**: Icon library
- **SVG icons**: When custom icons are needed

## Development Tools
- **ESLint**: Code linting
- **Prettier**: Code formatting
- **TypeScript**: Static type checking

## Component Architecture
- **TypeScript interfaces**: For type definitions
- **React hooks**: For state management and side effects
- **Functional components**: With TypeScript

## Styling Guidelines
- Use Tailwind utility classes whenever possible
- For dynamic styling, use inline styles with TypeScript
- Avoid creating custom CSS files
- Avoid creating custom CSS classes
- Keep styling co-located with components
