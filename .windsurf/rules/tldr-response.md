# TL;DR Response Rule

## Context
This rule ensures that all responses begin with a very brief TL;DR summary of what is being communicated in the response.

## Requirement
- **Always start responses with "TL;DR: " followed by a very brief summary**
- The summary should be 1-2 sentences maximum
- It should capture the main point or conclusion of the response
- After the TL;DR, continue with the detailed response as normal

## Examples
- "TL;DR: The logging mechanism works perfectly with only minor encoding issues."
- "TL;DR: Implementation complete and functioning as expected."
- "TL;DR: Found two minor issues but overall functionality is correct."

## When to Apply
- Apply to ALL responses regardless of topic or complexity
- Use for both technical explanations and status updates
- Maintain consistency across all interactions
